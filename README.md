# TCGiSOLux-Master-Plugin-Interior---Fort-Dawnguard
TCGiSOLux Master Plugin Interior - Fort Dawnguard

Turns the empty Dawnguard Base into a second base to Volkihar Clan after completion quest "Destroying the Dawnguard".

After completing the quest "Destroying the Dawnguard", the empty Dawnguard base will now become an second base for the Volkihar Clan. This mod will dynamically overhaul the interior as a second base for Volkihar Clan. Once the quest is complete, a delay is implemented to make the change more gradual and feel more organic.

This small, dynamic change is designed to enhance the commercial activity around Dayspring Canyon, and is highly compatible with other mods.

*** This mod requires the latest TCGiSO Master Plugin Inerior, found here.
*** Ok to install mid-game.

CONCEPT:

Skyrim's world space tends to feel very static. Despite a civil war, dragon attacks, and a rising vampire menace, not much ever changes. If the player could notice visible changes taking place over time it would help make the land of Skyrim feel more alive. It would help give a sense that events were occurring and time was passing throughout a playthrough. Ideally, these changes should be as seamless as possible with the base game. This mod attempts to implement this idea to at a handful of locations.

DETAILS:

This mod overhauls the Dawnguard HQ with a new interior that changes after the quest. 13 NPCs are implemented to fit into the game as well as possible, including Volkihar Clan Base dialogue and AI packages to 1:1 from the NPCs from Dawnguard.

To trigger the change, you must complete the quest "Destroying the Dawnguard" for Volkihar Clan. Once done, you must wait at least 7 days in game. The mod implements this by placing invisible trigger boxes that check and set these requirements when you pass through them, just outside each gate into Dawnguard HQ. Passing through any of them is necessary to read that quest is done, and to enable the new second base Volkihar Clan HQ once enough time has passed.

Important Note:
This mod does not actually change the Dawnguard HQ interior. Rather, it simply adds a new interior cell, switches out the exterior doors, and also replaces beds to vampire coffins in new interior, and turns to second base Volkihar Clan HQ. The empty Dawnguard HQ is completely untouched, and can still be accessed only via console or via cave.
